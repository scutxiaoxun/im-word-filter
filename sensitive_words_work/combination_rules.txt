#  作用：检测“单看不违规，合在一起违规”的场景（A+B+C逻辑）
#  支持三种格式，请根据业务需求选择

# ------------------------------------------------------------
# 格式1（最简洁）：只有关键词列表，用 + 连接
# 效果：所有关键词必须同时出现才触发拦截
# 示例：当 "甲"、"乙"、"丙" 同时出现在一句话中时拦截
# ------------------------------------------------------------
甲+乙+丙

# ------------------------------------------------------------
# 格式2（推荐）：规则名称 | 关键词列表 | 触发阈值
# 效果：命中其中任意 "阈值" 个即触发，灵活性最高
# 示例：规则名称为 "颜色组合"，关键词为 红/黄/蓝，阈值=2
#       即输入中只要出现 "红+黄"、"红+蓝" 或 "黄+蓝" 即拦截
# ------------------------------------------------------------
颜色组合|红+黄+蓝|2

# ------------------------------------------------------------
# 格式3：规则名称 | 关键词列表（省略阈值）
# 效果：默认阈值=关键词总数（即全匹配）
# 示例：规则名称为 "人名组合"，关键词为 张三/李四/王五
#       即 "张三"、"李四"、"王五" 必须全部出现才触发
# ------------------------------------------------------------
人名组合|张三+李四+王五
